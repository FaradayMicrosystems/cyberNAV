# cyberNAV

A navigation app with a retrofuturistic phosphor-CRT look, built for the phone and Android Auto.

```
CYBERNAV // NAV PLOT LIVE
```

| Path | What |
| --- | --- |
| [`docs/PLAN.md`](docs/PLAN.md) | Build plan for the Android Auto navigation app |
| [`docs/phosphor-hud/`](docs/phosphor-hud/) | Copy of the Phosphor HUD style guide (tokens, components, map styling) |
| [`docs/TESTING.md`](docs/TESTING.md) | How to try it: browser, APK, Android Auto, and the test suites |
| `simulator/` | Shared navigation core (routing, guidance, GPS handling, Android Auto template model) plus the phone and car UIs, runnable in a browser |
| `android/` | Android app: the phone UI in a WebView, and an Android Auto navigation app that draws the same map on the car surface |

**Download the APK:** https://github.com/FaradayMicrosystems/cyberNAV/releases/tag/prototype-latest (rebuilt by GitHub Actions on every push).
